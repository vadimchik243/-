Как участвовать

  1. Подключите EVM‑кошелёк (например, MetaMask).
  2. Выполните задания ниже — система начислит баллы.
  3. Нажмите «Забрать токены». Мы подпишем сообщение для подтверждения владения адресом — без газ‑комиссии.

Важно: мы никогда не запрашиваем приватные ключи или seed‑фразы. Запрашивается только подпись произвольного сообщения.

FAQ

Это настоящие токены?

NBL — вымышленный учебный токен. По желанию вы можете развернуть реальный ERC‑20 в тестовой сети и привязать контракт к кнопке «Забрать токены».

Есть ли газ‑комиссия?

Для подписи сообщения — нет. Для реального клима в блокчейне потребуется газ соответствующей сети.

Как подключить реальный бэкенд?

Укажите адрес вашего API в переменной API_BASE внутри app.js. Бэкенд может проверять подпись и ставить адрес в очередь на распределение.
