# NebulaDrop — демо аирдропа вымышленного токена NBL

Это статический сайт аирдропа, готовый к деплою на GitHub Pages, Vercel, Netlify или любой статический хостинг.

## Быстрый старт
1. Разместите содержимое папки на статическом хостинге.
2. Откройте `index.html` — кнопка «Подключить кошелек» работает с MetaMask (или другим injected провайдером).
3. Нажмите «Забрать токены» — система попросит **подписать сообщение** (без газа). Данные можно отправить на ваш бэкенд.

> По умолчанию отправка уходит в `localStorage` браузера. Чтобы включить реальный API — задайте `API_BASE` в `app.js`.

## Подключение реального контракта
Если хотите выдать реальные тестовые токены:
- Разверните ERC‑20 из `contracts/NBLToken.sol` в тестовой сети (например, Sepolia).
- Разверните `contracts/NBLAirdropDistributor.sol`, укажите адрес токена и пополните контракт токенами.
- Замените логику `claimAirdrop()` на вызов метода дистрибьютора (через ethers.js) — потребуется газ у пользователя.

## Безопасность
- Никогда не запрашивайте приватные ключи и seed‑фразы.
- Храните подписи на сервере и проверяйте их через `ecrecover` или `ethers.utils.verifyMessage`.

## Стек
- Чистый HTML/CSS/JS, без сборки.
- ethers.js (CDN) для подключения кошелька и подписи сообщений.
